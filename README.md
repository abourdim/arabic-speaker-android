# 🗣️ Arabic Speaker — Android wrapper

Capacitor wrapper that packages the [arabic-speaker](https://github.com/abourdim/arabic-speaker) web app as an installable **Android APK**.

> متحدث العربية · Arabic Speaker

Fully client-side Arabic Text-to-Speech and Speech-to-Text app. Multiple dialects (ar-SA, ar-EG, ar-AE, ar-MA, etc.), voice selection, adjustable rate/pitch/volume. No backend, no tracking. TTS works offline.

## Quick start

```bash
./manage.sh    # auto-detects your OS, then opens the menu
```

Build, test on emulator, and prepare a Play Store release from a single guided menu. See [WORKSHOP.html](WORKSHOP.html) for the full step-by-step guide.

## Download the latest APK

[📦 v1.0-debug release](https://github.com/abourdim/arabic-speaker-android/releases/latest) · [![QR](releases/download-qr.svg)](https://github.com/abourdim/arabic-speaker-android/releases/latest)

Scan the QR with an Android phone, or `adb install -r arabic-speaker-v1.0-debug.apk`.

## Capabilities required at runtime

- Standard WebView (no special hardware)
